# Opt-in CUDA overlay for local GPU training. CI does not install this file.
#
# requirements-rl-locked.txt resolves to a CPU-only torch on Windows, because it
# pins a bare `torch==2.13.0` with no index: PyPI's Windows torch wheel is the
# CPU build, and CUDA builds for Windows exist only on download.pytorch.org.
#
# The `sys_platform == 'linux'` markers on the nvidia-* wheels are NOT the cause
# and are not a misdetection -- they are correct guards that Windows rightly
# evaluates as false. On Linux, PyPI's torch is CUDA-enabled and pulls those
# packages as dependencies, which is why a universal lockfile lists them at all.
# On Windows the CUDA runtime ships inside the torch wheel as bundled DLLs, so
# no nvidia-* package is installed even when CUDA is working.
#
# Apply this AFTER requirements-rl-locked.txt, and only with --no-deps: the
# PyTorch index mirrors older copies of shared transitive dependencies, and a
# full resolve against it downgrades pillow 12.3.0 -> 12.2.0 and setuptools
# 83.0.0 -> 78.1.0, reintroducing CVEs the main lockfile already fixes.
#
#   python -m pip install -r requirements-rl-cuda-locked.txt --no-deps
#
# Same torch version as the shared lockfile, so only the CUDA variant changes.
# Requires an NVIDIA driver supporting CUDA 13.0+ (verified: RTX 4090, cc8.9).
--index-url https://download.pytorch.org/whl/cu130

torch==2.13.0+cu130
torchvision==0.28.0+cu130
